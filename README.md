# My Fairly Morning 🌅

Telegram-бот для хорошего начала дня, отслеживания привычек и саморефлексии.

## Возможности
- Утренний чек-лист привычек
- Вечерняя рефлексия
- Визуализация прогресса
- бонус (ввиде печеньки с предсказанием)

## Стек
- Python 3.14.5
- aiogram 3.x
- SQLite
- matplotlib
